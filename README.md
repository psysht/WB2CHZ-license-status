# WB2CHZ license status

Публичный подписанный реестр действующих лицензий приложения WB2CHZ.

Репозиторий не содержит исходный код приложения, файлы лицензий, имена клиентов или закрытые
ключи. В `licenses.json` публикуются только SHA-256-хеши случайных идентификаторов лицензий,
период действия реестра и цифровая подпись.

Файл формируется в приватном проекте WB2CHZ командой:

```powershell
.\tools\New-LicenseRegistry.ps1
```

Редактировать `licenses.json` вручную нельзя: WB2CHZ отклонит файл с неверной подписью.
