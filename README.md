# WB2CHZ License Status

Публичный подписанный реестр действующих лицензий приложения **WB2CHZ**.

Приложение загружает файл [`licenses.json`](./licenses.json), проверяет его цифровую подпись и
наличие хеша установленной лицензии в списке действующих. Реестр одинаков для всех экземпляров
WB2CHZ: приложение не отправляет на GitHub идентификатор лицензии или сведения о пользователе.

## Какие данные опубликованы

В репозитории находятся только:

- SHA-256-хеши случайных идентификаторов действующих лицензий;
- дата формирования и срок действия реестра;
- цифровая подпись содержимого.

По опубликованному хешу нельзя практически восстановить случайный UUID лицензии. Репозиторий не
содержит имена клиентов, исходные идентификаторы, файлы лицензий, исходный код WB2CHZ и закрытый
ключ подписи.

## Как это работает

1. Владелец WB2CHZ формирует реестр в закрытом проекте.
2. Реестр подписывается закрытым RSA-ключом.
3. Подписанный `licenses.json` публикуется в этом репозитории.
4. WB2CHZ проверяет подпись встроенным открытым ключом и ищет хеш своей лицензии.
5. При отсутствии хеша лицензия считается недействующей или отозванной.

После успешной проверки приложение сохраняет локальный кэш реестра до окончания указанного в нём
срока действия. Для первой проверки требуется доступ к GitHub.

## Обслуживание реестра

Файл создаётся инструментом `tools/New-LicenseRegistry.ps1` из закрытого проекта WB2CHZ. Для отзыва
лицензии используется `tools/Revoke-License.ps1`, после чего обновлённый реестр публикуется здесь.

> [!WARNING]
> Не добавляйте в этот репозиторий файлы `WB2CHZ.license`, закрытый ключ, сведения о клиентах или
> исходные идентификаторы лицензий. Не редактируйте `licenses.json` вручную: изменение нарушит
> цифровую подпись, и приложение отклонит реестр.

## Лицензия

Содержимое этого репозитория служит только для проверки статуса лицензий WB2CHZ. Публикация реестра
не предоставляет лицензию на использование приложения или его исходного кода.
